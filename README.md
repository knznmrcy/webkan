# KanztDev — refined anime portfolio

## Preview
Extract ZIP, then open `index.html` in a modern browser. Keep `kanzt-character.png` in the same folder as `index.html`.

## Customize before publishing
- Replace `hello@example.com` with your email.
- Replace GitHub, Instagram, and TikTok placeholder URLs with your profiles.
- Update project cards and skill levels to match your actual work and abilities.
- Edit the bio in the About panel.

## Publish free
**GitHub Pages:** create a repository, upload both `index.html` and `kanzt-character.png`, then go to Settings → Pages → Deploy from a branch → `main` / root → Save.
**Netlify:** drag the extracted folder into Netlify's manual deploy page.

The design is original and anime-inspired, using red/black/white colors, bold cutout-style menu lettering, a split-screen layout, keyboard navigation, and responsive mobile styling. It is not affiliated with or an official Persona 5 asset.
